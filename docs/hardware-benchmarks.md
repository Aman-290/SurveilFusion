## How To Contribute Results

1. Record camera count, stream resolution, codec, and detection FPS.
2. Note model format: PyTorch, ONNX, OpenVINO, TensorRT, Hailo, or CoreML.
3. Include CPU, RAM, temperature, and dropped-frame observations.
4. Open a pull request with the benchmark table updated.
